Code

Released implementations, sensor drivers and capture tooling. Most of this work runs on hardware anyone can buy, so the code is the shortest path to reproducing a result.

Start here

Track a hidden object in three steps

  1. Order the ST evaluation kit — about $50.
  2. Clone consumer-nlos and follow the setup instructions.
  3. Track objects around a corner in real time, at 30 Hz.
